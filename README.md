# Agent Documentation

## Installation

Give your coding agent this repository URL and ask it to read
`DEVELOPMENT-STANDARD.md`, then initialize the project documentation structure.

```text
https://github.com/fitri/agent-documentation
```

## Purpose

Standard project documentation workflow and definitions for AI agents.

The standard helps agents initialize, understand, maintain, verify, and hand
off project work without duplicating or accumulating stale documentation.

## Contents

- `DEVELOPMENT-STANDARD.md` — the complete reusable standard.

## Versioning

Use a tagged release of `DEVELOPMENT-STANDARD.md` when initializing a project.
Do not automatically pull an unspecified or moving latest version.
